- Local-first `youtube-breakout` CLI.
- Public `yt-dlp` search and metadata collection.
- Per-channel median baselines and channel-normalized outlier scoring.
- Small-channel and established-channel breakout lists.
- Optional public comments, subtitles, and local thumbnail metrics.
- Generic, walking, and AI-automation niche configurations.
- Evidence-led Markdown/JSON/CSV outputs.
- `PATTERN_BANK` with evidence, counterexamples, unknowns, and next tests.
- Source ledger and immutable run artifacts.
- Anonymous deterministic offline fixtures.
- Standalone Hermes Agent Skill.
- Privacy and release-gate scripts.
- Complete English-first and Russian-second release documentation.
- Python 3.10–3.12 CI plus built-wheel installed-package offline fixture smoke.
